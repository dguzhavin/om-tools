# Бэкап тестовой модели PY_SDK ##1.0

Сюда кладётся zip-бэкап модели, на которой гонялся стенд. Из него модель восстанавливается в любом
Workspace 9.200, и стенд можно запустить с `env_examples/` почти без изменений (поменяются только
id модели и, возможно, longId объектов).

## Какой бэкап брать

- `#47329` (2026-09-23) **не подходит**: он сделан до того, как в модели появились `SDK_PROBE_LIST`,
  `bool_cube`, `scr1`, роль, UAM-справочник и дашборд.
- Подходит свежий бэкап, сделанный после всех прогонов. `model.backup()` из SDK бэкап не создаёт
  (см. справочник), поэтому делать его в интерфейсе, а скачать можно так:
  `await model.get_backup("#<номер>")` или прямо из интерфейса.

## Перед коммитом

Репозиторий публичный. В бэкапе лежит вся модель, включая справочник пользователей с e-mail
коллег и права. Перед коммитом либо удалите лишних пользователей из модели и сделайте бэкап
заново, либо храните бэкап не здесь (приватное хранилище, ссылка в этом README).
